# Anime Clip｜极简动漫素材裁剪器

这是一个本机运行的动漫视频素材裁剪工具。它只保留一条清晰工作流：

1. 粘贴公开视频链接，或选择本地视频；
2. 解析并预览完整视频；
3. 选择国家、动画作品和目标人物 IP；
4. 可选上传一张目标人物近景参考图；
5. 手动填写开始、结束时间和任意图片数量；
6. 只从目标人物候选画面中筛选变化明显的高清帧，同时生成视频片段；
7. 分别下载、打包成 ZIP，或直接保存到选定的本地文件夹。

页面不再提供动画版本、集数、任务记录等冗余流程，但保留了作品与人物选择。时间范围、目标人物、图片数量和素材分类均由用户直接决定。

## 启动

环境要求：Node.js 22.13 或更高版本。解析 B站、抖音、快手等公开视频链接还需要 Python 3、`yt-dlp` 和 `curl-cffi`：

```powershell
python -m pip install --upgrade yt-dlp curl-cffi
```

可以直接双击：

```text
启动动漫表情提取器.bat
```

或者在 PowerShell 中运行：

```powershell
cd "E:\广研一个月\新任务\动漫表情提取器"
npm run dev -- --hostname 127.0.0.1
```

然后打开 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)。启动命令会同时运行：

- `5173`：极简裁剪界面；
- `5174`：公开视频链接解析与支持 Range 的本机流式桥接服务。

## 使用方法

### 1. 添加视频

- 链接模式：粘贴公开可访问的视频页面地址，然后点击“解析完整视频”；
- 支持直接粘贴 B站、抖音、快手、小红书等平台分享文案，输入框会自动去掉平台前缀、标题和多余文字，只保留 `http://` 或 `https://` 开头的视频链接；
- 本地模式：点击“选择本地视频”；
- 解析完成后，页面会显示标题、时长、分辨率、编码和完整视频播放器。
- 对于把声音和画面分开的平台视频，系统会同时解析音频轨道，并在完整视频预览中同步播放声音。

### 2. 选择作品和目标人物

当前目录提供日本动画和美国动画两组经典作品，包括《哆啦A梦》《蜡笔小新》《名侦探柯南》《宝可梦》《航海王》《火影忍者》《龙珠》《樱桃小丸子》《猫和老鼠》《恶搞之家》《辛普森一家》《海绵宝宝》《乐一通》《米奇与朋友们》《史酷比》和《南方公园》等。

选择作品后继续选择目标人物。部分代表性角色带有内置配色预设；也可以上传一张只包含目标人物的清晰近景参考图。参考图的颜色分布会实际参与视频局部区域匹配，不只是分类标签。没有内置预设的人物必须上传参考图。

### 3. 定义素材范围与数量

开始和结束时间支持以下格式：

- `75.5`：75.5 秒；
- `01:15.5`：1 分 15.5 秒；
- `00:01:15.5`：1 小时制时间码。

也可以先拖动播放器，再点击“使用当前”把当前时间写入开始或结束输入框。图片数量可以输入 `1—100` 之间的任意整数，不再限制为固定档位。

### 4. 生成人物素材并导出

点击“生成图片帧和视频片段”后，浏览器会：

- 在所选时间段内进行比目标输出数量更密集的候选扫描；
- 使用人物参考图分区颜色相似度和内置角色配色预设筛选目标人物；
- 结合画面运动、细节变化和时间间隔，优先选择变化较明显且不密集重复的候选；
- 目标人物不在时间段内时返回“未找到”，不会为了凑数量输出明显错误的其他人物；
- 从原视频画面生成最高 1920 像素宽、JPEG 质量 0.92 的图片帧；
- 按真实开始和结束时间播放并重新编码视频片段；
- 浏览器支持时优先输出 MP4/H.264，否则输出 WebM；
- 在页面中直接预览每张图片和裁剪视频。

生成完成后可使用：

- 单张图片下载；
- 单个视频片段下载；
- 完整素材 ZIP 下载；
- “保存到本地文件夹”，直接选择一个目录写入全部素材。

## 输出目录

目录按“作品 → 人物 → 情绪/素材分类”自动生成。例如选择《哆啦A梦》、哆啦A梦和 `Surprise` 后，结构为：

```text
Doraemon/
└── Doraemon/
    └── Surprise/
        ├── Frames/
        │   ├── frame_001_00-03.2.jpg
        │   ├── frame_002_00-04.6.jpg
        │   └── ...
        ├── Clips/
        │   └── clip_00-03.0_00-10.0.mp4
        └── manifest.json
```

ZIP 还会包含 `README.txt`。`manifest.json` 记录作品、目标人物、参考图名称、筛选方式、人物相似度、画面变化分数、精确时间、分辨率、视频格式和生成时间。

## 预览声音与原视频下载

公开平台常使用 DASH，把画面和音频拆成两条轨道。链接解析时会同时获取高清画面轨道和音频轨道；完整视频播放器会在浏览器内同步两条轨道，因此播放、暂停、拖动、倍速和音量控制都包含声音。

“下载原始视频画面轨道”下载的仍然是未经重新编码的高清画面轨道，裁剪出的片段目前也默认不含音频。也就是说：页面中的完整视频预览有声音，但素材视频导出暂时只包含画面。

本地上传模式下，“下载原始视频”会保存用户选中的原文件副本。

## 支持边界

- 只解析匿名状态下公开可访问的页面，不读取浏览器 Cookie；
- 不绕过登录、付费、地区限制、DRM 或其他访问控制；
- 平台页面结构和反爬规则变化时，个别链接可能暂时无法解析；
- 合集链接默认解析 URL 指向的当前分P，如需其他分P，请使用带 `?p=` 的完整页面地址；
- 浏览器能否解码取决于视频编码，推荐 MP4/H.264；
- 生成视频片段需要真实经过对应片段时长，例如裁剪 10 秒视频通常至少需要约 10 秒；
- 当前人物识别是本地视觉候选器，不是训练完成的人物身份大模型；相似度用于排序和拒绝明显错误画面，最终人物身份与情绪仍建议人工复核；
- 只有配色预设可能被相近颜色的背景干扰，上传目标人物近景参考图能提高筛选可靠性；
- 请只处理有权使用的素材，并自行确认平台条款与内容授权。

## 核心文件

- `app/expression-extractor.tsx`：视频载入、作品/人物选择、参考图、时间范围、数量和导出界面；
- `lib/character-catalog.ts`：日本和美国经典动画及人物 IP 目录、代表性角色视觉预设；
- `lib/browser-analyzer.ts`：目标人物候选筛选、变化排序、原分辨率图片帧提取与指定时间段视频编码；
- `scripts/media-link-bridge.mjs`：公开视频页面解析、临时令牌、Range 流式代理与原视频画面轨道下载；
- `启动动漫表情提取器.bat`：Windows 一键启动入口。
